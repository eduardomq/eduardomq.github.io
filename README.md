# eduardomq.github.io

Web de apoyo de [Amiiteca](https://github.com/eduardomq). No se edita aquí: la fuente vive
en la carpeta `web/` del repo de la app y se sube desde allí.

- `/.well-known/assetlinks.json`: declara que la app `com.edu.amiiteca` puede abrir los
  enlaces de este dominio (App Links). La huella es la de su clave de firma.
- `/404.html`: GitHub Pages lo sirve para cualquier ruta que no existe, así que hace de
  página de cada amiibo compartido, `/amiiteca/a/<código>`.
- `/amiiteca/`: qué es la app. `logo.png` es el icono de la app sobre su rojo de marca
  (`#e60012`), y sirve también de vista previa al compartir un enlace.
- `/favicon.png`: el mismo icono, pequeño.
